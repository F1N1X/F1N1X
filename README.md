## `> whoami`

```java
public final class Steven {

    private final String alias = "F1N1X";
    private final String focus = "Java Backend Engineering";

    void evolve() {
        learn();
        build();
        understand();
        refactor();
        repeat();
    }
}
```

I build software because I want to understand **how systems actually work**.

My focus is not collecting technologies or filling a profile with buzzwords.

I want to become better at building software that is:

`readable` · `maintainable` · `testable` · `secure` · `well structured`

I care about the engineering decisions behind a solution:

```text
Why this abstraction?
Why this dependency?
Why this boundary?
Why this architecture?

Can it be simpler?
Can it be clearer?
Will it still be understandable six months from now?
```
