## `> whoami`

```java
public final class Steven {

    private final String alias = "F1N1X";
    private final String focus = "Java Backend Engineering";

    void evolve() {
        learn();
        build();
        understand();
        refactor();
        repeat();
    }
}
```

I build software because I want to understand **how systems actually work**.

My focus is not collecting technologies.

I want to become better at building systems that stay:

`readable` · `maintainable` · `testable` · `secure` · `understandable`

```text
Why this abstraction?
Why this dependency?
Why this boundary?
Why this architecture?

Can it be simpler?
Can it be clearer?
Can it evolve without becoming fragile?
```
