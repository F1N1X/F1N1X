## `> whoami`

```java
public final class Steven {

    private final String alias = "F1N1X";
    private final String focus = "Java Backend Engineering";

    void evolve() {
        learn();
        build();
        understand();
        refactor();
        repeat();
    }
}
```

I build software because I want to understand **how systems really work**.

My goal is not to collect technologies.

My goal is to become better at building software that is:

`readable` · `maintainable` · `testable` · `secure` · `well structured`

I care about the decisions behind good software:

```text
Why this abstraction?
Why this boundary?
Why this architecture?
Can it be simpler?
Can it be clearer?
Will it still make sense in six months?
```
